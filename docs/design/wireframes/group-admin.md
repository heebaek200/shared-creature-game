# 그룹 관리 와이어프레임

[화면 설계서로 돌아가기](../../screen-design.md#12-그룹-관리-화면)

```text
┌──────────────────────────────────────────────────────────────┐
│ 그룹 관리       [구성원] [초대 링크] [크리처 선택]         │
├──────────────────────────────────────────────────────────────┤
│ 푸른잎  부 관리자  마지막 접속 2시간 전                     │
│                         [권한 회수] [강퇴]                   │
│ 햇살    일반        마지막 접속 4일 전                      │
│                         [부 관리자 지정] [강퇴]              │
│ 구름    일반        마지막 접속 1시간 전                    │
│                         [부 관리자 지정] [강퇴 비활성]       │
├──────────────────────────────────────────────────────────────┤
│ 주 관리자 이전 [대상 선택 ▾] [이전]                         │
└──────────────────────────────────────────────────────────────┘
```

- 부 관리자로 접속하면 권한·초대 재발급·이전 동작을 숨기고 72시간 미접속 일반 회원 강퇴만 제공합니다.
- 강퇴·권한·링크 재발급은 영향 설명과 사유를 포함한 확인 Modal을 사용합니다.

```text
└──────────────────────────────────────────────────────────────┘
```
