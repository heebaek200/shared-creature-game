### 다른 아바타 선택

```text
┌──────────────────────────────┐
│ 푸른잎 · 그룹 3위 · 1,820점 │
│ HEAD  새싹 모자 [상점에서 보기]│
│ FACE  나뭇잎 안경 [상점에서 보기]│
│ BODY  기본 외형             │
│ ACCESSORY  별 장식          │
└──────────────────────────────┘
```

- 모바일에서는 본문을 한 열로 쌓고 하단 내비게이션을 표시합니다.
- 알 상태에서는 성장 단계 대신 부화 남은 시간과 선택 상태를 강조합니다.
- 최대 20개의 안정적인 이동 구역을 사용하고 모바일에서는 선택한 아바타만 이름표를 표시합니다.
- 모션 감소 설정에서는 같은 위치에 정적으로 배치합니다.
- 헤더의 프로필 앞에서 `실시간 연결됨`, `재연결 중`, `30초 동기화 중` 상태를 확인합니다.
