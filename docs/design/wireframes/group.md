# 현재 그룹 와이어프레임

[화면 설계서로 돌아가기](../../screen-design.md#10-랭킹과-그룹-화면)

```text
┌──────────────────────────────────────────────────────────────┐
│ 새싹 연구소                         인원 14 / 20             │
│ 주 관리자 새싹지기                  [그룹 관리]              │
├──────────────────────────────────────────────────────────────┤
│ 구성원                                                       │
│ 새싹지기       [주 관리자]       마지막 활동 방금 전         │
│ 푸른잎         [부 관리자]       마지막 활동 2시간 전 [신고] │
│ 햇살           [일반]            마지막 활동 1일 전   [신고] │
│ ...                                                          │
├──────────────────────────────────────────────────────────────┤
│                                              [그룹 탈퇴]     │
└──────────────────────────────────────────────────────────────┘
```

- 그룹 관리 버튼은 `PRIMARY`, `DEPUTY`에게만 표시합니다.
- 주 관리자에게는 이전 대상 지정 전 탈퇴할 수 없다는 안내를 표시합니다.
- 신고 Modal은 분류와 10~1000자 내용을 입력받으며 접수 후 전체 관리자 검토 대상이라는 점을 안내합니다.
