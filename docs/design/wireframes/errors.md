# 403·404 오류 화면 와이어프레임

[화면 설계서로 돌아가기](../../screen-design.md#2-화면-경로)

```text
┌──────────────────────────────────────────┐
│                  403                     │
│ 이 화면을 볼 권한이 없습니다.            │
│ [내 기본 화면으로] [이전 화면]           │
├──────────────────────────────────────────┤
│                  404                     │
│ 요청한 화면을 찾을 수 없습니다.           │
│ [홈으로]                                 │
└──────────────────────────────────────────┘
```

- 내부 예외나 서버 경로를 노출하지 않고 사용 가능한 안전한 이동만 제공합니다.
