```text
┌──────────────┬───────────────────────────────────────────────┐
│ 관리자 메뉴 │ 운영 경고        [유형 ▾] [상태 ▾] [갱신]   │
├──────────────┼───────────────────────────────────────────────┤
│              │ FAILED · 주간 퀘스트 배정 · 00:00 KST       │

│              │ 인원 불일치 · 새싹 연구소 14 / 실제 13      │
│              │ 주 관리자 복구 · 그룹 선택 · 대상 선택 [재지정]│
```

- 별도 알림 읽음 상태가 아니라 원본 업무 상태가 정상화되면 경고가 해소됩니다.
- 주 관리자 재지정은 전체 관리자만 실행하며 현재 활성 회원을 대상으로 확인 Modal과 감사 사유를 받습니다.
