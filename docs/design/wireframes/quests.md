# 퀘스트 와이어프레임

[화면 설계서로 돌아가기](../../screen-design.md#9-퀘스트-화면)

```text
┌──────────────────────────────────────────────────────────────┐
│ 퀘스트                     갱신 00:00 KST                    │
│ [일일 3] [주간 7]                                           │
├──────────────────────────────────────────────────────────────┤
│ 하 · 물 한 잔 마시기        +100 XP · 기여 10   [완료하기] │
│ 중 · 10분 운동              +100 XP · 기여 20   [처리 중]  │
│ 상 · 아침 체크인            +100 XP · 기여 30   [완료 ✓]   │
├──────────────────────────────────────────────────────────────┤
│ 검증 방식·남은 기간·실패 이유 영역                          │
└──────────────────────────────────────────────────────────────┘
```

- `PHOTO_EXIF` 배정에는 사진 선택·제출 UI와 GPS·촬영 시각 누락을 포함한 판정 실패 이유를 표시합니다.
- 업로드 영역에는 `JPEG · 최대 10 MB`를 표시하고 HEIC·HEIF 선택 시 JPEG 재촬영·내보내기 안내를 제공합니다.
- `GPS·촬영 시각만 확인하며 실외 여부나 실제 이동은 검증하지 않습니다`라는 안내를 표시합니다.
- 완료·기간 종료 상태에서도 보상 Snapshot을 확인할 수 있습니다.
