```text
┌──────────────────────────────────────────────────────────────┐
│ 그룹 선택                                    프로필·테마     │
│ [그룹명 검색________________] [검색]       [+ 새 그룹 생성] │
├──────────────────────────────────────────────────────────────┤
│ 새싹 연구소        14 / 20    남은 자리 6       [가입]       │
│ 느긋한 숲          20 / 20    정원 마감          [비활성]     │

├──────────────────────────────────────────────────────────────┤
│                  < 1  2  3 >                                │
│ 24시간 제한 종료 시각·남은 시간 또는 업무 오류              │
└──────────────────────────────────────────────────────────────┘
```

### 새 그룹 생성 Modal

```text
┌──────────────────────────────┐
│ 새 그룹 만들기              │
│ 그룹명 [________________]    │
│ 2~30자·전역 중복 도움말      │
│ [취소]          [생성]       │
└──────────────────────────────┘
```

- 제한 중에는 가입·생성 버튼을 비활성화하고 종료 시 서버 상태를 재조회합니다.
- 그룹 생성 성공 시 자동 생성된 초대 링크를 한 번 표시하고 복사 동작을 제공합니다. 이후 원문을 잃으면 그룹 관리 화면에서 재발급합니다.
