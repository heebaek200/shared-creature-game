# 초대 링크 와이어프레임

[화면 설계서로 돌아가기](../../screen-design.md#4-소셜-로그인회원가입과-그룹-선택)

```text
┌──────────────────────────────────────────┐
│ 그룹 초대                               │
│ [그룹 대표 이미지]  새싹 연구소         │
│ 현재 인원 14 / 20   남은 자리 6         │
│                                          │
│ 초대를 수락하면 소셜 가입 후             │
│ 이 그룹 가입을 다시 확인합니다.          │
│                                          │
│ [초대 수락]              [거절]          │
│ 링크 상태·가입 실패 이유 영역            │
└──────────────────────────────────────────┘
```

- 무효 링크는 수락 버튼 대신 `일반 회원가입으로 이동`을 표시합니다.
- 수락은 자리를 예약하지 않는다는 안내를 함께 표시합니다.
