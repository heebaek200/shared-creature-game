# 회원가입 와이어프레임

[화면 설계서로 돌아가기](../../screen-design.md#14-가입초대그룹-선택-입력과-feedback)

```text
┌──────────────────────────────────────────┐
│ 회원가입                                │
│ 가입 방식   Google              읽기 전용│
│ 이메일     user@example.com     읽기 전용│
│                                          │
│ 닉네임                                   │
│ [ 새싹지기________________ ] [중복 확인] │
│ 2~20자 도움말·검증 메시지                │
│                                          │
│ [가입 완료]                              │
└──────────────────────────────────────────┘
```

- 제출 중 버튼을 비활성화하고 서버의 최종 중복 검사 결과를 표시합니다.
- 초대 문맥이 있으면 가입 완료와 그룹 가입을 함께 처리한다는 안내를 표시합니다.
