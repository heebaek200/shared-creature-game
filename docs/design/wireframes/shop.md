# 상점 와이어프레임

[화면 설계서로 돌아가기](../../screen-design.md#13-상점아바타결제환불-화면)

```text
┌──────────────────────────────────────────────────────────────┐
│ 아바타 상점       [전체] [HEAD] [FACE] [BODY] [ACCESSORY]   │
├──────────────────┬──────────────────┬────────────────────────┤
│ [상품 이미지]    │ [상품 이미지]    │ [상품 이미지]          │
│ 새싹 모자 HEAD   │ 나뭇잎 안경 FACE│ 숲 망토 BODY           │
│ 1,000원          │ 1,500원          │ 2,000원                │
│ [카카오페이 결제]│ [보유 중]        │ [판매 중지]            │
└──────────────────┴──────────────────┴────────────────────────┘
│ 결제 진행·결과 불명 Feedback                                │
└──────────────────────────────────────────────────────────────┘
```

- 결제 처리 중에는 해당 상품의 중복 결제 동작을 막습니다.
- 프로젝트에서는 포트원 V2 카카오페이 테스트 채널만 호출하며 별도 결제수단 선택 화면은 두지 않습니다.
