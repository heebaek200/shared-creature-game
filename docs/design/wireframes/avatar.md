# 아바타 와이어프레임

[화면 설계서로 돌아가기](../../screen-design.md#13-상점아바타결제환불-화면)

```text
┌──────────────────────────────────────────────────────────────┐
│ 내 아바타                                                   │
├───────────────────────────┬──────────────────────────────────┤
│      [아바타 미리보기]    │ 슬롯                             │
│                           │ HEAD      새싹 모자   [해제]      │
│                           │ FACE      선택 안 함 [선택]      │
│                           │ BODY      숲 망토     [장착]      │
│                           │ ACCESSORY 선택 안 함 [선택]      │
├───────────────────────────┴──────────────────────────────────┤
│ 보유 아이템: [미사용] [사용] [회수됨]                       │
└──────────────────────────────────────────────────────────────┘
```

- 미사용 아이템의 최초 장착은 환불 불가 전환 확인 Modal을 거칩니다.
- 회수된 아이템은 선택·장착 동작을 제공하지 않습니다.
