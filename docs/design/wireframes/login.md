# 로그인 와이어프레임

[화면 설계서로 돌아가기](../../screen-design.md#2-화면-경로)

## 데스크톱

```text
┌──────────────────────────────────────────────────────────────┐
│ 로고                                      테마 전환          │
├───────────────────────────┬──────────────────────────────────┤
│ 공동 크리처 일러스트      │ 다 같이 키우는 생명체           │
│ 자연·성장 소개 문구       │ 소셜 계정으로 시작하세요        │
│                           │ [ Google로 계속하기 ]           │
│                           │ [ Naver로 계속하기  ]           │
│                           │ 로그인 제한·오류 안내 영역      │
└───────────────────────────┴──────────────────────────────────┘
```

## 모바일

```text
┌────────────────────────────┐
│ 로고              테마     │
│                            │
│     크리처 일러스트        │
│  다 같이 키우는 생명체     │
│                            │
│ [ Google로 계속하기 ]      │
│ [ Naver로 계속하기  ]      │
│ 오류·검수 제한 안내        │
└────────────────────────────┘
```

- 비밀번호 입력은 제공하지 않습니다.
- 로그인 버튼 선택 후에는 중복 이동을 막고 진행 상태를 표시합니다.
- 동일 이메일의 다른 공급자 계정이 발견되면 기존 가입 공급자를 안내합니다.
