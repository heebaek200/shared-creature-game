## 2. 선택 검증(환경이 있을 때만)

- [ o ] 동일 결제 완료 요청 중복 처리 방지
- [ o ] 중복/역순 Webhook
- [ o ] 서명 위조 Webhook 거절
- [ o ] PG 응답 Timeout 및 취소 상태 복구

**선택 검증 결과/미실시 사유:**
#검증 완료
- 동일 결제 완료 요청 중복 처리 방지: 아이템 중복 지급 없이 보유 수량 1개 유지 확인
- 중복/역순 Webhook: 결제 완료 후 이전 결제 준비 이벤트가 도착해도 결제 상태 유지 확인
- 서명 위조 Webhook 거절: 잘못된 서명 요청에 HTTP 400 반환 확인
- PG 응답 Timeout 및 취소 상태 복구: Timeout 발생 후 환불 상태 복구 확인
- 환불·장착 동시 실행: 환불 진행 중인 아이템의 장착 요청이 차단되는 것 확인
- PC·모바일 결제 복귀 경로: 결제 완료 후 결제·환불 내역 화면으로 정상 복귀 확인
