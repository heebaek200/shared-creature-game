## TC-35-01 / PASS — 로그인

| 로그인 공급자 | 그룹 가입 사용자 | 그룹 미가입 사용자 |
| --- | --- | --- |
| Google | 크리처 홈으로 이동 | 그룹 선택 화면으로 이동 |
| 네이버 | 크리처 홈으로 이동 | 그룹 선택 화면으로 이동 |

**사용자 경험(UX)**

게임에서 로그아웃해도 네이버 로그인 세션이 유지되어 다른 계정 전환 시 네이버에서 별도로 로그아웃해야 했다.

같은 브라우저에서 다시 ‘네이버로 계속하기’를 눌렀을 때 다른 계정을 선택할 수 없는 사용 불편함이 있다.

공용 컴퓨터에서는 다음 사용자가 같은 브라우저에서 이전 사용자의 게임 계정으로 로그인하거나 네이버 계정을 무단 이용할 가능성이 있다.

## TC-35-02 / PASS — 그룹 생성 및 가입

- 새 그룹을 생성하자 주 관리자로 자동 가입됐고 그룹 관리 페이지에 접근할 수 있었다.
- 기존 그룹에는 일반 회원으로 가입할 수 있었고 기존 회원의 정보를 볼 수 있었다.

## TC-35-03 / PASS — 중복 그룹 가입 방지

그룹을 생성한 후 그룹 목록에서 가입 버튼이 비활성화됐고 가입 불가 메시지가 표시됐다. 판정 범위는 화면에서의 가입 차단이다.

**사용자 경험(UX)**

본인이 생성한 그룹에도 다른 그룹에 가입되어 있다는 메시지가 표시됐다.

**개선 제안**

본인 소속 그룹에는 ‘이미 해당 그룹에 가입되어 있습니다.’를 표시한다.

## TC-35-04 / PASS — 그룹 탈퇴

- 일반 회원과 부 관리자는 탈퇴 시 재가입 제한에 대한 안내를 받은 뒤 그룹 선택 화면으로 이동했다. 재가입 제한 시간과 안내 메시지가 적용됐다.
- 주 관리자는 권한 이전 전에는 탈퇴할 수 없었고, 다른 회원에게 권한을 이전한 후에는 탈퇴할 수 있었다.

## TC-35-05 / PASS — 회원가입

회원가입을 정상적으로 완료했다.

**버그 · 닉네임 형식 성공 메시지가 남음**

회원가입 화면에서 올바른 형식의 닉네임을 입력하고 형식 확인을 눌러 성공 메시지를 띄운 다음, 닉네임을 잘못된 형식으로 수정한다.

수정 후에도 이전 성공 메시지가 계속 표시됐다.

**개선 제안(UX)**

- ‘입력 형식 확인’ 버튼 이름을 ‘확인’으로 줄인다.
- 하단의 중복 여부 검사 안내 문구를 제거하고, 형식 확인 성공 메시지를 ‘올바른 닉네임 형식입니다.’로 줄인다.

## TC-35-06 / PASS — 초대 링크

| 실행 조건 | 실제 결과 |
| --- | --- |
| 비로그인 상태에서 초대 거절 | 로그인 화면으로 이동했다. |
| 비로그인 상태에서 초대 수락 | 로그인 화면으로 이동했다. |
| 초대 수락 후 타 그룹 소속 계정으로 로그인 | 기존 소속 그룹의 크리처 홈으로 이동했다. |
| 초대 수락 후 그룹 미소속 계정으로 로그인 | 초대된 그룹에 가입했다. |
| 초대 수락 후 새 계정으로 로그인 | 회원가입 화면으로 이동했고 회원가입 완료와 동시에 초대된 그룹에 가입했다. |
| 타 그룹 소속 계정으로 로그인한 상태에서 초대 링크 열기 | 안내 메시지가 표시됐고 수락 버튼이 비활성화됐다. |
| 그룹 미소속 계정으로 로그인한 상태에서 초대 링크 열기 | 초대를 수락할 수 있었다. |

## TC-35-07 / PASS — 관리자 권한 변경 후 그룹 관리 메뉴 접근

판정 범위는 역할 변경 후 그룹 관리 메뉴 접근이다.

| 권한 변경 | 실제 결과 |
| --- | --- |
| 주 관리자가 다른 회원에게 권한 이전 | 기존 주 관리자는 일반 회원이 됐다. 그룹 관리 메뉴에 접근할 수 없었고 그룹 페이지로 이동했다. |
| 일반 회원에게 부 관리자 권한 부여 | 그룹 관리 메뉴에 접근할 수 있었다. 초대 링크 관리에는 접근할 수 없었다. |
| 일반 회원 또는 부 관리자에게 주 관리자 권한 부여 | 그룹 관리 메뉴에 접근할 수 있었다. 초대 링크 관리에는 접근할 수 없었다. |

## TC-35-08 / FAIL — 회원 탈퇴 화면 미구현

DB 설계서에는 회원 탈퇴 시 계정 상태를 `WITHDRAWN`으로 변경하고 탈퇴 시각을 `withdrawn_at`에 기록한다고 정의되어 있다.

그러나 게임 계정 전체를 탈퇴하는 기능에 대한 실제 화면은 구현되어 있지 않음을 확인했다.

## TC-35-09 / NOT RUN — 그룹 가입 동시성 수동 테스트

서로 다른 미가입 테스트 계정 2개를 확보하지 못해 실제 계정으로 그룹에 동시에 가입하는 브라우저 테스트를 실행하지 못했다.

## TC-35-10 / NOT RUN — 정원 20명 초과 가입 방지 수동 테스트

활성 멤버가 20명인 테스트 그룹을 확보하지 못해 실제 계정으로 21번째 가입을 시도하는 브라우저 테스트를 실행하지 못했다.

## TC-35-11 / PASS — 그룹 가입 동시성 자동화 테스트

Gradle 테스트 보고서에서 2건 실행, 실패 0건, 건너뜀 0건을 확인했다. 검증 범위는 그룹 가입 서비스와 테스트용 MySQL이다.

- 활성 멤버 19명인 그룹에 두 사용자가 동시에 가입을 시도했다. 한 명만 가입에 성공했고, 다른 요청은 `GROUP_FULL`로 거절됐다.
  DB의 그룹 인원 카운터와 활성 멤버십 수는 각각 20이었다.

- 한 사용자가 서로 다른 두 그룹에 동시에 가입을 시도했다. 한 건만 성공했고, 다른 요청은 `ALREADY_IN_GROUP`으로 거절됐다. DB에 해당 사용자의 활성 멤버십이 1건 남았다.
