## 3. 비고

- **테스트 중 발견한 특이사항:**
- 모바일에서는 퀘스트 완료 후에도 추가 사진 제출로 횟수가 소모되는 것으로 관찰됐다.
- 모바일에서 완료 후 사진을 다시 제출했을 때 오류 메시지 없이 진행되지 않는 현상이 있었다.
- PC에서는 완료 후 사진을 다시 제출하면 성공 안내가 표시되고, 카운터는 감소하지 않는 것으로 관찰됐다.
- 모바일과 PC의 재제출 결과 차이는 동일 사용자·배정·사진 조건으로 추가 비교가 필요하다.
- Android 화면에서 사진 보관함 선택 경로는 확인했다.
- 카메라 직접 촬영 경로는 확인하지 못했다.
- **사진 퀘스트 결과 문서:** [QA-05-mobile-exif.md](QA-05-mobile-exif.md)

> 원본 사진 파일·EXIF GPS 좌표는 첨부하지 않습니다. 모바일 테스트를 수행하지 않았다면 PC의 결과를 모바일 결과로 바꾸어 기록하지 않습니다.
