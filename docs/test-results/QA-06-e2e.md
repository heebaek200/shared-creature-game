## 1. 기록 기준

| 판정 | 기준 |
|---|---|
| `PASS` | 기대 결과를 모두 확인함 |
| `FAIL` | 실행했으나 기대 결과와 다름. [결함 기록표](QA-06-defect-log.md)에 재현 절차를 남김 |
| `BLOCKED` | 계정·기기·외부 서비스·테스트 데이터 부족 등으로 실행할 수 없음 |
| `NOT RUN` | 아직 실행하지 않음 |

- 실제 결과에는 화면 문구와 상태 변화를 한 줄로 기록합니다.
- 테스트 계정, 세션 쿠키, OAuth·PG·Gemini Secret, 사진의 GPS 좌표는 기록하거나 커밋하지 않습니다.
- 결제는 PortOne 테스트 채널만 사용하고 실제 결제를 진행하지 않습니다.
- 결함 수정 후에는 같은 TC를 다시 실행하고 결함 기록표에 날짜와 결과를 남깁니다.
- `QA 피드백` 이슈는 모두 구현 대상이라는 의미가 아닙니다. `진행`, `스킵`, `보류` 중 하나를 기록하고, 스킵한 항목은 해결로 집계하지 않은 채 남는 사용자 영향과 시연 영향만 공개합니다.
