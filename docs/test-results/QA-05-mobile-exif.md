## 5. 테스트 데이터 변경 이력

- 사진 퀘스트 배정을 위해 로컬 SQL 시드의 일일·주간 템플릿을 사진 퀘스트 코드로 변경했다.
- 기존 일일 배정에는 완료 기록이 있어 사진 퀘스트로 교체되지 않았다.
- 주간 배정 ID 17에 W-X-01과 PHOTO_EXIF가 적용된 것을 확인했다.
- 시험 준비 후 변경한 SQL 파일의 두 줄은 원래대로 복구했다.
- DB에 적용한 주간 사진 퀘스트 배정의 원복 여부는 미확인이다.

## 6. 결과 요약

- **기본 4건:** PASS 3 / FAIL 0 / BLOCKED 1 / NOT RUN 0
- **실기기 검증 범위:** Android Chrome 보관함 사진 선택·제출
- **정상 확인:** 유효 JPEG 인증·보상, GPS 누락 거절, 완료 상태 유지, 배정별 제출 5회 제한
- **추가 발견:** 완료 후 재제출 안내 부족, 모바일·PC 재제출 동작 차이
- **개선 제안:** 주간 제출 기회의 날짜별 복구, 모바일 직접 촬영 흐름 검토
- **자동 테스트로 확인:** 동시 처리·Timeout, 사진 보존 기간 정리
- **미검증 범위:** iOS, 직접 촬영, 실제 HEIC·HEIF 서버 제출, 용량 경계, 분당 제한, 일부 시간·GPS 경계, 실기기 동시 처리와 실제 시간 경과 삭제

원본 사진, 개인 GPS 좌표, 촬영 장소는 이 문서에 첨부하지 않는다.
